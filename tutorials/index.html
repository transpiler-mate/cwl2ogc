Explore the notebook examples

These worked examples load a document and display the converted inputs and outputs. Read them in order or choose the CWL feature you want to explore.

  1. Essential input parameters
  2. Array inputs
  3. Records and unions
  4. Exclusive parameters with expressions
  5. Document graphs
  6. Complex CWL types
  7. Imported CWL types
  8. String formats
  9. JSON Schema generation and validation

To run the notebooks locally, clone the repository, install the example dependencies, and launch Jupyter from the repository root:

python -m pip install -e . jupyterlab cwl-loader jsonschema
jupyter lab

Open notebooks in docs/. Most examples fetch CWL documents from public URLs and require network access. The imported-types notebook also uses the checked-in tests/artifacts/ directory.
